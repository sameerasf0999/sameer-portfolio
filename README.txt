SAMEER ASIF | TRANSLATION & TRANSCRIPTION PORTFOLIO

FILES
- index.html : website content
- style.css  : design and responsive layout
- script.js  : mobile navigation and current year

HOW TO USE
1. Keep all three files in the same folder.
2. Open index.html in a browser to preview the website.
3. To publish with GitHub Pages, upload all three files to the root of your GitHub Pages repository.
4. In the repository, open Settings > Pages and choose Deploy from a branch, then select the main branch and /(root).

PERSONALIZE BEFORE PUBLISHING
- Add a contact method only if it is safe and appropriate, and ask a parent/guardian to help review it.
- The sample translations and transcription are demonstration practice examples, not paid client work.
- Do not add your home address, phone number, private documents, passwords, or other sensitive information.
- You may edit the text directly in index.html and the colors in style.css.

This is a static frontend. It does not collect form submissions or store visitor data.
